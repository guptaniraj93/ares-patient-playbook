# Ares Patient Operations Playbook

Interactive SOP for patient enrollment, CCM/RPM coordination, proactive outreach queues, communication templates and exception handling.

## Run locally

Open `index.html` in a browser. No dependencies or patient data are required.

## Scope

This is an operational SOP prototype, not a live CRM, EHR, RPM, telephony or clinical triage integration. Clinical protocols, SLAs, consent, access controls and privacy safeguards must be approved before production use.

**Systems:** CRM (to be selected), Aircall, ChronicCareIQ, Practice Fusion and Doxy.me.

**Patient communication:** phone-first; Aircall SMS for supplementary reminders; no patient portal or ChronicCareIQ patient messaging.
